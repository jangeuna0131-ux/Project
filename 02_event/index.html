[jquery 스타일 변경 메서드]

  1. $("선택자").css() -> 프로그램적으로 css 접근 함수
  2. $("선택자").show() -> 선택자를 숨겨져 있는 요소를 보이게 하는 함수
  3. $("선택자").hide() -> 선택자를 숨기는 함수
  4. $("선택자").toggle() -> 선택자를 한번 클릭하면 보이고 한번 클릭하면 숨김
  5. $("선택자").width() -> 선택자를 프로그램적으로 가로 사이즈 조절 함수
  6. $("선택자").height() -> 선택자를 프로그램적으로 세로 사이즈를 조절하는 함수
